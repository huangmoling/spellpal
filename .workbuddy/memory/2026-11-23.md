### 工具

- `.tmp/fill_src.py <bookId> <tr.tsv>`：把 `英文<TAB>中文[<TAB>修正英文]` 回填进 src，`DROP<TAB>英文` 删行。
  自动归一化弯引号，支持第三列修正 OCR 残缺的英文原句。
- `.tmp/walk.mjs <词...>`：CDP 里逐个打字 + 空格推进，遇到句子卡（h2 长度 > 8）就截图停下。
  验证例句 UI 用这个，比手点可靠。

### 标注器规则（annotate.py / build_lex.py）

- 词形还原补齐：`-ing/-ed` 短词（going/doing）、`-er/-est` 比较级（hotter）、
  否定缩写（didn't→没有）、`I'll/he'll`→会、序数词（12th）、连字符合成词（tree-planting）、
  单字母（the letter D→D）、班级代号（6A）、破折号分词（me—You）。
- `build_lex.py` 会清洗「释义=英文原文」的脏词条（历史模板语料的自指污染，248 条），
  且语料不再覆盖单词表已有释义。
- 专有名词误标用 `annotate.py` 的 `CTX`（按整句 + 下标覆盖）修，例：Sunny→桑尼、
  The Greens→格林一家、His name is Tiger→泰格。
- `build-books.mjs` 的 `shortCn()` 只取第一个义项，避免词块下出现「聚会，派对」。
